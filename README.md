## 🛠️ A Few Stories From Work

**The migration that shouldn't have worked.**
MySQL lets you `GROUP BY` sloppily. PostgreSQL doesn't. When our database migrated, half our reporting queries just stopped. Instead of rewriting years of queries by hand, I engineered a function that replicates MySQL's old behavior on top of Postgres — it still runs in production today.

**The module nobody wanted to touch.**
The Letter of Credit module had quietly rotted — the kind of code where every fix breaks something two files away. I took it apart, found out *why* it kept breaking, and rebuilt it into something the team can trust now.

**A formula system so clients stop asking for code changes.**
Every client wanted their dropdown values formatted differently. Instead of hardcoding one-offs, I built a customer-configurable, formula-based system — they define the format, no deploy needed.
